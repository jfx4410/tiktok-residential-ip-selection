## 原生 IP、家宽 IP、双 ISP，不是一回事

原生 IP 说的是 IP 注册地和服务器实际所在国一致，TikTok 识别出来就是当地用户。家宽 IP 说的是这个 IP 挂在当地 ISP 的家庭宽带下面，ISP 类型被识别成“住宅”。两者能同时满足，也可以只满足一个。

WePC 套餐页会把这两种分开标：写“原生 IPv4”的和写“原生家宽 IPv4”的不是同一档货。英国就是个现成例子，普通原生 IDC AUD$10.90，原生家宽 AUD$14.90，配置一模一样，差 AUD$4.00，差的就是 IP 归属类型。

双 ISP 是加分项，指同一个 IP 在两个运营商名下都有注册记录，网络稳定性和识别信任度比单 ISP 高一档。美国洛杉矶两款、韩国、马来西亚、菲律宾、日本、新西兰都是双 ISP 版本。

下单前只做一件事：把套餐名读完，看清楚写的是原生还是原生家宽。

## 常见问题

**家宽 IP 和原生 IP 到底差在哪？**

原生只保证 IP 归属地是当地，家宽还要求这个 IP 挂在当地 ISP 的家庭宽带上。TikTok 风控看的是后者，所以同样配置下家宽款更贵。WePC 两个都卖，套餐名里写得很清楚。

**优惠码输了没减钱怎么办？**

先确认套餐在不在例外名单里。台湾、新加坡、美国家宽系列的部分住宅 IP 套餐不支持优惠码，这是已知情况，不是码失效。

**直播一定要买中转吗？**

看套餐和你的宽带。标“无需中转”的（洛杉矶两档、墨尔本、日本直播线路、英国直播线路）三网直连就能推；标“建议中转”或“必须中转”的，电信方向基本都要配，否则晚高峰掉流。

**澳大利亚、韩国、日本多少钱？**

韩国 AUD$19.90、日本标准版 AUD$19.90、日本直播线路 AUD$49.90、墨尔本和悉尼都是 AUD$19.90。澳大利亚早前没有公开报价，现在官网已经挂出来了。
